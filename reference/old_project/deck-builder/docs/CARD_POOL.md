# Card Pool

Generated by reading every `CardData` resource under `resources/cards/`
directly (not derived from any in-game roll). Read-only export — nothing
in the project was changed to produce this.

**Scope decisions:**
- `resources/cards/classes/wanderer/retired/heavy_blow.tres` is **excluded**
  from the table below. `CardPool.load_class_pool()` only scans files
  directly inside a class's pool folder (no subdirectory recursion), so a
  `retired/` subfolder is structurally unreachable by any in-game path
  today — same exclusion technique this project uses elsewhere (e.g. the
  opening room's own enemies). It's dead content, not part of the current
  pool. For the record: Heavy Blow was a CLOSER, "Deal 12 damage," 2
  energy.
- **The Samurai class** (renamed from "Rogue" 2026-09-03) has an **empty**
  card pool — `resources/cards/classes/samurai/` holds only a `.gitkeep`.
  Its two former cards, Shadow Step and Backstab, were deleted in the
  rename. Nothing from this class appears in the table below. (It also
  isn't reachable in an actual run: `RunState.current_class` is hardcoded
  to Wanderer, no character-select UI.)
- **`npc_offers/` cards** (Held Position, Second Wind, Left Hand) are real,
  active content, but acquired only by accepting a specific field NPC's
  offer — never rolled into the normal reward pool. Noted in the
  Rarity/Acquisition column as "NPC offer" rather than a rarity tier,
  since `rarity` isn't what gates how a player actually gets them.
- **Packed Sand**, **Kept Coin**, and **Split Shell**
  (`resources/cards/packed_sand.tres`, `resources/cards/kept_coin.tres`,
  `resources/cards/split_shell.tres`) are new since this doc was first
  generated — root-level, like Slash/Guard/Bite Down, so also outside
  `CardPool.load_class_pool()`'s scan. Acquired only as the wreckage
  heap's own weighted `GRANT_CARD` outcome (`sift_outcomes.tres`, weighted
  0.6/0.4/0.4 — roughly 43%/29%/29%), shown as a click-to-take-or-walk-away
  field offer. Noted as "Heap offer" in the Rarity/Acquisition column,
  same shape as "NPC offer" above. All three are `removal_scope =
  CONSUMED` and have no `upgrades` entry.
- "Type: other" in the request maps to `STANCE`, the one non-Attack/Skill
  type that exists today (Selfeater is the only card that uses it) - the
  table below reports the literal type name rather than collapsing it to
  "other."
- **Starter-deck rework (2026-09-05)**: `STARTING_DECK` is now `SLASH:
  3, BITE_DOWN: 2, BRACE: 2, RECKONING: 1, DOWN_PAYMENT: 1` (9 cards,
  was `STRIKE: 5, GUARD: 5, BITE_DOWN: 1`, 11 cards). **Brace** and
  **Down Payment** (`resources/cards/brace.tres`,
  `resources/cards/down_payment.tres`) are new, root-level, Starter-only
  cards — like Slash/Bite Down, they sit outside every class's
  `card_pool_folder`, so they can never be rolled as a reward.
  **Reckoning** is the one card that's BOTH: still in the Wanderer class
  pool (reward/shop-rollable, unchanged) AND now also preloaded directly
  into the starter deck, so its own Starter column below changes to
  "Yes" without leaving the reward pool.
- **Guard is now RETIRED** (2026-09-05, same pass) — briefly a live
  Wanderer class-pool card after moving out of the starter deck, then
  moved again into `resources/cards/classes/wanderer/retired/guard.tres`
  in the very same pass, matching Heavy Blow's own precedent exactly
  (see this doc's first bullet). **Excluded from the table below**, same
  as Heavy Blow — `CardPool.load_class_pool()`'s own scan doesn't
  recurse into `retired/`, so it's structurally unreachable by any
  in-game path today. For the record: Guard was a 1-cost Skill, "Gain 5
  block," upgrading to "Gain 8 block" (`guard_plus.tres`, which stays at
  its own unchanged location and is now unreferenced by anything live).
- **Forbearance** (`resources/cards/classes/wanderer/forbearance.tres`,
  same pass, renamed from "Shore Up") is new: a live Wanderer
  class-pool card (reward/shop-rollable, not a Starter), granting the
  new `ABSORB` effect type - a second, independent damage-reduction
  pool from block, persisting until spent rather than clearing each
  turn. See `docs/DESIGN.md`'s own absorb note for the full mechanical
  rundown.
- **Strike renamed to Slash** (2026-09-05, same pass) —
  `resources/cards/strike.tres`/`resources/cards/upgrades/strike_plus.tres`
  moved to `slash.tres`/`slash_plus.tres` at their same respective
  locations (root-level starter card; upgrade under `upgrades/`). No
  mechanical change - same effect (`DAMAGE`, value 6, upgrading to 9),
  same Starter status, same pool exclusion. `run_state.gd`'s own
  `STRIKE` preload const is now `SLASH`.

**Data-quality notes, found while reading, not corrected (this is a
read-only export):**
- **Second Wind** describes a conditional bonus clause ("If your hand is
  empty after playing this, draw 1 more") that has no corresponding
  second `CardEffect` in the resource - only the base effect (2 draw) is
  actually implemented. The text states an intended design that isn't
  mechanically backed yet. (Held Position's own matching clause, listed
  here in an earlier pass, has since been wired up - see its table row's
  `[cond_active]` bonus below, backed by a real `bonus_value` now.)
- **Advance** and **Come To** use `SELF_DAMAGE_TOLL`, not plain
  `SELF_DAMAGE` (Bite Down's kind) - their HP loss is floored at 1 and can
  never kill the player, unlike Bite Down's, which can. The table's HP
  Cost column doesn't distinguish the two; noted here since it's a real
  difference in what "costs HP" means per card.
- **Kept Coin** doesn't set `card_type` in its resource, so it defaults to
  `ATTACK` despite its own effect being a pure utility grant ("Gain 2
  energy this turn.", no damage). Affects its card-face border color
  (`card.gd`) and would count as an Attack for anything that reads
  `card_type` (nothing does today) - flagged, not corrected.

## Cards that reference Toll or Rally explicitly

Scoped to literal mentions of the word in a card's own `description` or
`flavor_text` — not cards that mechanically touch Toll through their
`CardEffect.effect_type` without saying so in the text (see Come To in the
data-quality notes above: it uses `SELF_DAMAGE_TOLL`, which still accrues
Toll through the normal per-HP-lost path, but the card's own text never
says "Toll").

### Toll

- **Advance** — "Gain 10 Toll."
- **Compound** — "If Toll is 15 or more, deal 16 damage instead."
- **Owed in Full** (and its upgrade, Owed in Full+) — "Spend half/all your
  Toll to deal bonus damage."
- **Paid in Pain** — "Spend 7 Toll."
- **Reckoning** — "Consume all Toll."
- **Retaliation** — "Spend 5 Toll."

### Rally

No cards reference Rally explicitly today. Rally (the Wanderer's own
recovery-pool passive) currently has zero card-text touchpoints - it's
driven entirely by combat events (unblocked enemy damage taken, damage
dealt), not by anything a card's own description mentions.
